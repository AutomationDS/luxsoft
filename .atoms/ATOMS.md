# Project Context

## Project Overview
LuxeCart - A full-fledged aesthetic e-commerce website with 6 product categories, modern fluid UI with vibrant colors, complete shopping flow including cart, checkout, wishlist, and order history.

## Constraints
- Color Palette: Deep Indigo (#4F46E5) primary, Coral (#F97316) CTA accent, Teal (#0D9488) secondary, warm neutrals
- Typography: System font stack with Inter-like feel, clean and readable
- Layout: Full-width hero, category grid, product cards with hover animations
- Visual: Smooth transitions, gradient accents, subtle shadows, fluid animations
- Web Design Style: Modern marketplace with glassmorphism touches, vibrant gradients
- Order history accessible from user profile
